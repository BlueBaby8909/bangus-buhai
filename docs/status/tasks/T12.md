## Work completed

Owner-confirmed choices: correct only manual entries; allow partial measured
observations; reject estimates; permit audited restoration; archived tank history
is readable and manual writes require tank restoration.

AI implemented:

- [Readings feature](../../../rebuild/backend/features/readings/README.md): typed
  protected history/detail and manual create/correct/void/restore/revision APIs,
  finite measured values, explicit missing metrics, UTC measurement timestamps,
  five-minute future tolerance, notes/instrument and actor attribution.
- Retried creation uses a hatchery/operator request UUID. Identical original
  content returns the current entry; changed content/tank conflicts. Mutations
  recheck membership and tank eligibility under T11's hatchery lock. Expected
  versions prevent lost updates. Device telemetry is never edited.
- [Migration 0004_t12](../../../rebuild/backend/database/migrations/versions/0004_t12.py)
  and database models: immutable manual identity/revisions, committed history
  counter and append-only journal with restrictive/composite ownership FKs.
  Triggers atomically index new telemetry/manual revisions, enforce manual version
  sequence and reject history rewriting/deletion. Existing telemetry is backfilled
  by reference, without payload, timestamp, device or binding changes. Command
  results/identical retries allocate no journal position.
- Signed scope/filter-bound cursors retain a committed watermark and select
  manual revisions as of that point. New, backdated, corrected, voided and pending
  transaction records cannot reorder an ongoing page sequence. Explicit receipt
  view includes unsynchronized captures with null measured_at. No guessed times,
  sensor calibration or biological/model eligibility is inferred.
- Shared application router/error composition; existing session/origin/CSRF,
  HTTPS, request-size and no-store behavior retained. Health/main.py unchanged.
- 27 new real-PostgreSQL/HTTP integration tests and 3 offline unit tests. Existing
  migration-head assertions updated; CI discovery/check labels include readings.
