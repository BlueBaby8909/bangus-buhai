  deadlines and revocation are persistent; no passwords/plaintext cookie tokens.

  serialized refresh; immediate persistent local logout/disable; reusable
  operator/hatchery dependencies. Authentication permissions use local mapping
  and memberships, never email or provider database-role claims.

  responses, HTTP development restricted to loopback, production HTTPS/Secure
  cookies, bounded provider requests and shared fixed-minute throttling at ten
  attempts per IP. Supplied launcher ignores forwarded headers.

  memberships and disables accounts; no role flag/public enrollment endpoint.
  No regular application accounts/hatcheries were seeded.

  previous dependency pins. Extended the existing offline runner and PostgreSQL
  CI job with generated-key/mock-provider checks; no cloud secrets in CI.

  settings. At the owner's request saved their supplied publishable key and
  project URL, preserving the generated encryption key and all other settings.
  Private configuration remains ignored; contents are not copied into this record.
- Updated PRD/roadmap/decision/reference/setup/status documents for the approved
  operator-only design. Historic T09 evidence retains its original scope.
