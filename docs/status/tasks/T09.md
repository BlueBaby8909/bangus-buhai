## Work completed

- Added `rebuild/backend/database/`: lazy explicit configuration/pooling,
  transaction-scoped SQLModel sessions, seven foundation tables, append-only
  event persistence, local setup CLI, migration CLI and frozen Alembic revision
  `migrations/versions/0001_t09.py`. App `/health` and wire contracts unchanged.
- Tables: hatcheries, user identities, memberships, tanks, devices, bindings,
  device events. Composite FKs reject cross-owner bindings/event attribution.
  Canonical external device IDs are globally unique and distinct from UUID row
  IDs. Membership roles are constrained. Resource IDs/owners/external IDs cannot
  be rewritten. Names can change. User identities have no authentication mapping
  or credentials yet; actual authorization/RLS is not claimed.
- Several devices can share a tank; partial unique index enforces one open
  binding per device. Close-and-replace retains history. DB triggers reject
  binding identity/start changes, reopening and deletion; event updates/deletes
  are rejected. Referenced resource deletion is restricted, not cascaded.
- Shared unique `(device UUID, boot UUID, seq)` covers both event kinds, with
  uint32 bounds. JSONB preserves validated metric values, validity, provenance,
  ages, diagnostics and original timestamp strings. Capture time is nullable;
  server receipt time never substitutes for it. Race-safe INSERT/ON CONFLICT
  compares through T02 semantics; changed content/kind raises event_conflict.
  The helper does not commit/ACK, enroll resources or authenticate a publisher.
- Added `rebuild/database/compose.yaml`, init SQL, secret-free `.env.example` and
  README. Dedicated project/volume, PostgreSQL 18, loopback port 55432, separate
  rebuild development/test DBs. Local CLI creates random ignored credentials once,
  preserves an existing `.env`, never resets data, and supports up/status/stop.
  Initial native verification used temporary files/mocked Docker failure for the
  generator. Final Docker setup generated the ignored rebuild `.env` once with
