## Goal and finish conditions

Give firmware, backend and later browser adapters one versioned definition of device messages, with shared examples and executable checks. Valid readings/commands/results must be accepted; malformed, mismatched or conflicting data must be rejected according to documented rules. Failed/default/estimated readings, capture time and command outcomes must retain their actual meaning. This establishes message correctness, not live transport, device trust or hardware behavior.
